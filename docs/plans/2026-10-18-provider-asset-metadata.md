# 服务图标的非绘图元数据

Gemini SVG 内嵌的 JPEG 带有 11,904 字节的 Adobe XMP APP1 段。
删除该段并保留其余 JPEG 字节，不重新编码图片，不改 SVG 路径、渐变、
裁切、尺寸或其他绘图属性。该段没有 license、rights 或 copyright 字段；
既有第三方声明保持原样。

基于 `10d726e`，相同 Vite 生产配置的独立构建中，总产物从 1,352,389
降到 1,336,518 字节；逐文件 gzip 总和从 406,356 降到 399,180 字节。
gzip 使用 Node zlib 默认压缩等级 6，JavaScript 总量仍为 1,183,263 字节。
以上是前端产物测量，不能直接
换算成原生安装包的压缩差值。

内嵌 JPEG 的 472 × 461 RGB 解码像素完全相同；SVG 的绘图元素与属性
逐项相同。Chromium 在 16、24、32、36、48、64、72、192、384 像素
九种输出尺寸的 RGBA 差异均为零。没有新增依赖或远程资源，也没有
移除图标表示、缩减分辨率或调整发布压缩配置。
