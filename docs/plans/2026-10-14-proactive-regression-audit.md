# 主动回归检查：翻译完成、录音授权与迟到操作

本轮只修复能够重现的现有行为，沿用当前产品和共享运行时边界。

## 约束

- 阿里 Qwen MT 的部分流式结果只能作为预览。HTTP 正常 EOF 不能单独
  证明翻译完成；`finish_reason=stop` 或 `[DONE]` 提供完成证据。
  显式长度限制、内容过滤等失败不能提交确认字幕。错误保持无正文，
  保留正常 JSON、流式响应以及现有取消、重试、截止时间策略。
  协议依据：[Qwen-MT API](https://help.aliyun.com/zh/model-studio/qwen-mt-api)
  与 [SSE 完成信号](https://www.alibabacloud.com/help/en/model-studio/stream)。
- Windows 输出设备实际改变后撤销当前录音勾选，与输入类型和应用捕获
  来源切换一致；同一草稿中的录音开启不能跨过来源变化。后续可显式
  重新开启。原生保存、当前会话清除和前端乐观状态遵循同一规则。
- 共用配置输入框等待剪贴板时允许继续编辑。任何更新的字段编辑或值
  替换都使旧读取失效，包括改后又改回；迟到结果不能覆盖或自动保存。
- macOS 跟随系统的原生菜单使用完整首选界面语言，保留中文脚本和地区，
  不使用格式化地区的基础语言码。设置、托盘与应用菜单继续共用解析器。

## 验证

每项新增回归先在旧实现失败，再在修复后通过。翻译逻辑只修改
`shared/mimi-runtime`，通过共享 fixtures、直接 Rust 和实际 Android JNI
验证；不增加 Kotlin 翻译实现。桌面来源保存和前端状态分别覆盖真实
变化、相同来源、组合草稿、后续重新开启以及失败恢复。

完整检查使用 `./scripts/check.sh`。受影响输入控件与菜单在签名
`/Applications/mimi-dev.app` 的无凭据 UI 模式检查。Windows 真机录制、
真实服务故障与 Android 设备捕获需要单独证据，不能由模拟测试推断。
