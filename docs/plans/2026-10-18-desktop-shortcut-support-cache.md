# 桌面快捷键能力查询复用

设置页、会话控件和原生就绪检查共享一份 WebView 内的查询。首次读取
进行中时合并请求，成功后复用结果，包括表示原生快捷键的 `null`。
卸载一个消费者仅阻止其状态更新，不取消其他消费者所需的读取。

原生结果由当前进程的平台、显示会话、安装路径和固定命令参数决定，
不包含可修改的用户快捷键偏好；WebView 重新加载后仍会重新检查。
不跨窗口共享缓存，不持久化结果，也不改变任何 IPC 或平台回退规则。

失败继续保持能力未知，不把错误当作成功缓存。后续消费者可重新发起
查询；不增加后台重试。回归覆盖三个并发消费者、成功后重新挂载、
失败后重试，以及全部卸载后迟到的成功／失败和浏览器预览回退。
