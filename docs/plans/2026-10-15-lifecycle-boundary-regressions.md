# 迟到事件、录音恢复与语言包准备边界

本轮基于 `e5b7746e`，并行检查已有功能；只修改有失败回归支持的边界。

- 已确认句子退出实时配对表后，带该句 response ID 的迟到译文草稿仍有
  身份，不能退化成无身份草稿覆盖新句。缺少可靠来源映射时丢弃该草稿；
  真正没有身份的旧协议事件继续沿用已有兼容路径。直接 Rust 和实际
  Android JNI 重放同一份配对契约，不能另外实现 Kotlin 规则。
- 录音收尾因已有 WAV 损坏或不匹配而失败时，保留下来的 PCM journal
  仍是当前会话音频的来源。播放／导出从 PCM 构造 WAV，不能优先读失败
  的旧输出；已归档、没有 PCM 的会话继续读取正式 WAV。失败不消费
  journal 或覆盖已有文件；当前录音关闭后的访问门禁保持不变。
- Apple 翻译语言包的准备回调必须属于某一次具体的页面／配置／语言对
  上下文。离开后返回相同参数仍是新上下文，旧回调不能取消新查询、写入
  旧状态或恢复旧错误。实际准备操作保持单次执行，完成后释放 busy 状态，
  当前查询决定重新进入页面后的资源状态。

验证先证明旧实现失败，再重放相同案例和相邻正常路径。原生 UI-only
用于界面检查；模拟异步结果、临时音频文件及合成字幕不能证明真实服务
频率、系统资源下载或用户硬件捕获。发布版本不属于本轮任务。
