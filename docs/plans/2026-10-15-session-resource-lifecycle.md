# 记录页资源与翻译超时生命周期

本轮基于 `bdc1ecc8`，为补丁版候选检查性能、内存和已有功能边界。
只修复可复现的多余工作或错误时序，不调整采集队列、共享字幕策略、
服务协议、签名或发布压缩参数。

## 记录页

- 设置页通过 CSS 隐藏记录页以保留用户选择和播放状态。隐藏期间停止
  archive 状态轮询；重新进入时立即读取新状态。组件 lifetime 与可见性
  分开，离页不能让已发起的删除失去 catalog 更新或让 busy 永久保留。
- 同一组件最多保留一个尚未完成的录音读取。播放按钮在读取时禁用，
  同一事件轮内的重复触发也由同步 guard 阻止；失败后恢复重试。
- 切换记录或音源仍使旧结果失效；页面往返保留既有播放和选择语义。
  不为减少内存而停止用户已发起的播放，也不通过增加音频缓存去重。

## 翻译超时

桌面适配器先让共享 controller 接纳 `TranslationStarted`，再读取该次
pending deadline 并安装定时任务。deadline 在派发前捕获，不能依赖
Tokio worker 与 reducer 的偶然先后。保持 source、generation、task ID、
内容锁及取消保护，超时策略仍由共享实现定义。

## 验证与范围

先用同一回归证明旧行为失败，再覆盖隐藏／返回、重复操作、错误重试、
迟到回复、删除与双音源等相邻路径。资源改善以实际请求数和容量边界
表述，不把短时 RSS 观察或组件测试换算为长期内存／CPU 改善百分比。
包体积使用相同生产构建配置比较；开发 bundle 不作为发布体积基线。
发布、真实服务、原生 UI 和设备验收分别记录，不互相替代。
