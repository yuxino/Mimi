「設定 → 一般」で表示言語を選べます。簡体字中国語、繁体字中国語、英語、日本語、ドイツ語、韓国語、フランス語、タイ語に対応しています。「システムに従う」はシステムの言語を使用します。表示言語を変えても編集中の内容や字幕の状態は維持されます。認識言語と翻訳先の言語は別に選んでください。

## インストールと更新

1. [最新リリース](https://github.com/yuxino/mimi/releases/latest)から macOS の Apple シリコン／Intel 用 DMG、Windows x64 の EXE／MSI／ポータブル ZIP、または Linux x86_64 の .deb／AppImage をダウンロードします。ソースからのビルドも可能です。
2. 「設定 → 音声と翻訳」で設定を追加し、サービスの認証情報を入力して保存します。認識言語と翻訳先の言語を選びます。
3. 音声を再生し、「字幕」で「リアルタイム字幕」をオンにします。メニューバー／システムトレイの mimi アイコンからも開始できます。macOS 14.2 以降は、すべてのアプリと特定のアプリのどちらでもシステム音声のみの録音権限を使用できます。既存の画面収録権限は引き続き使用し、音声のみの権限を別途要求しません。macOS 13–14.1 は画面とシステム音声の収録権限が必要です。

サービスの API 認証情報は自分で用意してください。利用料金が発生する場合があります。デスクトップ版の認証情報は、ファイル権限で保護された端末内の非公開の平文ファイルに保存されます。

macOS、Windows のインストーラー版、Linux AppImage は「設定 → 一般 → ソフトウェアアップデート」から更新できます。ダウンロードの進捗が表示され、完了後にインストールできます。Windows はインストール後に Mimi を開き直します。macOS と Linux AppImage は「再起動して更新を完了」を選べます。v1.3.8 より前のバージョンは、一度手動でインストールしてからアプリ内更新を利用してください。

独自の WebSocket サービス、自動判定と言語ヒントの違い、各サービスの対応言語は[音声サービスと言語の設定（英語）](speech-language-setup.md#english)をご覧ください。

### 対応プラットフォーム

- macOS 13 以降（Apple シリコン／Intel）：Apple シリコンは `_aarch64.dmg`、Intel は `_x64.dmg` を選びます。Intel 版は v1.4.4 から提供しています。ビルドと署名の確認は済んでいますが、Intel 実機での音声取得や権限の挙動は未検証です。DMG は Apple の公証を受けていません。初回起動がブロックされた場合は「システム設定 → プライバシーとセキュリティ」で「このまま開く」を選んでください。旧版からの更新時は、下の権限に関する説明も確認してください。
- Windows x64：未署名のプレビュー版 EXE／MSI と、v1.4.3 以降のポータブル ZIP を提供しています。SmartScreen の警告が出る場合があります。`mimi_<version>_x64-portable.zip` を展開し、`mimi.exe` を実行します。WebView2 が必要です（Windows 11 では通常インストール済みです）。設定や非公開の認証情報ファイルはアプリのユーザーディレクトリ、書き出したファイルは指定した場所に保存され、ZIP のフォルダへは移動しません。更新は Mimi を終了して新しい ZIP に置き換えてください。ポータブル版はアプリ内のインストーラー更新を実行しません。
- Linux x86_64 プレビュー版（Ubuntu 22.04 以降を基準）：`.deb` と AppImage を提供しています。PulseAudio または `pipewire-pulse` を有効にした PipeWire、使用可能な既定の出力デバイス、非公開の認証情報ファイルへのアクセスが必要です。システム音声は出力のモニターから取得します。出力デバイスを変えたらセッションを再開してください。X11 を推奨します。Wayland の位置指定、最前面表示、クリック透過はデスクトップ環境に制限される場合があります。Mimi の設定に表示されるコマンドを使い、システムのキーボード設定でショートカットを登録してください。トレイアイコンがなくても設定画面から操作できます。最小化すると動作を続けますが、設定画面を閉じると Mimi が終了します。Linux ARM64 版は提供していません。[Linux の導入と検証（英語）](development/linux.md)をご覧ください。

### macOS のシステム音声の権限

macOS 14.2 以降の新規インストールでは、全アプリと特定アプリのどちらでもシステム音声のみの録音権限を要求します。既存の許可を切り替える場合は Mimi を終了し、「システム設定 → プライバシーとセキュリティ」で画面とシステム音声の収録の Mimi の項目を削除またはオフにしてから、Mimi を開いて字幕を開始してください。表示される確認でシステム音声のみの録音を許可するか、その権限の一覧で Mimi をオンにします。再起動を求められたら従ってください。切り替えは任意で、既存の画面収録の許可も引き続き使えます。権限不足のエラーからシステムの権限画面を開き、許可と必要な再起動を行ってから再試行できます。

### 更新後に macOS が権限を再度求める場合

現在の macOS リリースは同じ固定の自己署名証明書を使います。v1.4.1 以前はビルドごとに変わる一時的な署名を使用していたため、固定の署名に初めて更新する際に録音の許可が一度必要になる場合があります。ソースの修正はインストール済みの旧版の署名を変えません。固定署名はビルドごとの識別情報の変更を防ぎますが、macOS が二度と許可を求めない保証ではありません。端末の署名証明書を削除しても、インストール済みアプリの識別情報は変わりません。正式版は `/Applications/mimi.app`、開発版は `/Applications/mimi-dev.app` を使ってください。それぞれ署名設定と録音権限を別に保持し、開発版は正式版で変更した署名を引き継ぎません。

許可済みなのに取得できない場合は、まず Mimi を終了して開き直し、通常の許可画面に従ってください。それでも取得できない場合：

1. 問題のアプリを終了します。「システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音」（名称は macOS の版により異なります）で、正式版なら **mimi**、開発版なら **mimi-dev** の古い項目だけを削除します。
2. + で対応する `/Applications/mimi.app` または `/Applications/mimi-dev.app` を追加し、権限をオンにします。システムの認証は自分で行ってください。別の Mimi や他のアプリの項目は残します。
3. 同じアプリを開き直し、ショートカットや開始ボタンで字幕を開始します。人の声が含まれる音声を再生し、字幕が実際に表示されることを確認してください。権限のスイッチがオンになっているだけでは復旧の確認になりません。

削除するのは古い録音の許可で、証明書や API キーではありません。一度試しても直らない場合はリセットを繰り返さず、macOS と Mimi のバージョン、インストール元、エラーを添えて[不具合を報告](https://github.com/yuxino/mimi/issues)してください。API キーや字幕の内容は含めないでください。

旧システムの認証情報は一度だけ自動移行し、非公開の平文ファイルへの保存を確認してから元の項目を削除します。移行時に旧認証情報の読み取り許可が必要な場合があります。移行後の切り替え、保存、更新はこのファイルのみを使い、欠損や破損時もキーチェーンへ戻りません。`codesign` による署名用秘密鍵へのアクセスは、別のビルド時の確認です。

## サービスの設定

デスクトップ版では、各サービス設定に認識言語と翻訳先の組み合わせを保存できます。設定を有効にして言語を選び、「設定 → 音声と翻訳」で詳細を開いて「現在の言語を記憶」を選びます。変更や解除は「現在の言語に更新」または「保存を解除」で明示的に行います。

設定を切り替えたり適用し直したりすると、保存した言語の組み合わせに戻ります。一時的な言語変更は保存内容を上書きしません。トレイと字幕のメニューには、設定名の下に保存した言語が表示されます。字幕上部のサービス情報から、現在の設定の詳細を開けます。

## 音声と記録の保存

初期設定ではシステム音声を使用します。設定や字幕の操作パネルでシステム音声、マイク、または両方を選べます。マイクはシステムの既定の入力を使い、実際の取得開始時に必要な権限を求めます。両方を選ぶと認識接続、字幕、サービス利用量はそれぞれ独立します。入力を変えると録音はオフになります。必要なら「保存と書き出し」で再度オンにしてください。

macOS と Windows build 20348 以降では、アプリ選択画面で特定のアプリの音声を選べます。Linux はシステム出力のモニターを使用し、この選択画面はありません。

「設定 → 保存と書き出し」で字幕の保存や選択した音声入力の録音を設定します。どちらも初期設定はオフです。オンにするとセッション中に端末の非公開ファイルへ順次保存し、システム音声とマイクは分けて保存します。オフにすると今回の該当する内容を消去します。保存済みの記録は明示的な削除が必要です。

次のセッションを開始しても、画面内の件数制限付きの確定字幕は残ります。「クリア」で消去できます。これによって字幕保存がオンになったり、旧字幕が新しい記録にコピーされたり、終了後に未保存の字幕が復元されたりすることはありません。

字幕は確定済みの 10,000 件／テキスト 2 MiB、音声は 64 MiB が上限です。上限に達すると保存を停止し、通知します。字幕の時刻は確定時刻です。WAV は一時停止や再接続の空白を省くため、両者の時刻はそのまま対応しません。

## 字幕の表示

設定で 5 種類の色（初期設定は白）を選ぶか、その後ろのカスタム色からシステムのカラーピッカーを開けます。システム音声とマイクの色は個別に設定します。プレビューと字幕はすぐに更新され、イマーシブモードでも有効です。二言語表示では原文を翻訳より控えめな明暗で表示します。

「時刻を表示」は字幕設定と操作パネルにあり、初期設定はオフです。オンにすると両入力の確定字幕の横に端末の確定時刻（HH:mm:ss）が表示されます。イマーシブモードでも有効で、発話の開始時刻ではありません。システム音声だけに戻しても、残っているマイクの字幕には入力元の小さなアイコンが付きます。操作パネルで一時停止／再開もできます。

設定、字幕の操作パネル、トレイで「翻訳のみ」「原文＋翻訳」「原文のみ」を選べます。macOS は ⌘⇧B、Windows／Linux X11 は Ctrl+Shift+B ですぐに切り替えられ、翻訳を中断しません。Wayland はシステム設定で `mimi --cycle-subtitle-display` にショートカットを割り当ててください。二言語表示は確定した原文と翻訳を対にして表示し、翻訳待ちの間は認識した原文を先に表示します。

「字幕を早めに表示」がオンの場合、後から変わる可能性がある下書きを表示します。オフの場合は確定結果を待つため、話し続けると表示まで長くかかる場合があります。下書きが保存済みの履歴になる設定ではありません。

## 音声認識のエラー

認識に失敗しても既存の字幕は残り、理由を表示し続けます。操作パネルを開くと詳しい説明と復旧操作が表示されます。設定の問題には「音声と翻訳」の入口、一時的な接続やサービスの問題には再試行を表示します。該当の設定を修正または切り替えると、失敗したセッションは待機状態に戻り、音声取得は始まりません。準備ができてから「リアルタイム字幕」を再度オンにしてください。
