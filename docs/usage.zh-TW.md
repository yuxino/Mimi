## 安裝與更新

1. 從[最新版本](https://github.com/yuxino/mimi/releases/latest)下載 macOS Apple 晶片或 Intel DMG、Windows x64 EXE／MSI／可攜版 ZIP，或 Linux x86_64 .deb／AppImage；也可以從原始碼建置。
2. 開啟「設定 → 語音與翻譯」，新增設定，依提示輸入服務商認證資訊並儲存，再選擇辨識與翻譯語言。
3. 播放內容，在「字幕」頁開啟「即時字幕」，也可從選單列／系統匣的 mimi 圖示按「開始」。macOS 14.2 及以上，擷取「所有應用程式」或指定應用程式均支援僅系統音訊錄製權限；既有的螢幕錄製授權會繼續使用，不會另外要求僅系統音訊授權。macOS 13–14.1 需要螢幕與系統音訊錄製權限。

需要自行準備服務商 API 認證資訊，呼叫可能產生費用。桌面版認證資訊儲存在受本機檔案權限保護的私有明文檔案中。

macOS、Windows 安裝版和 Linux AppImage 可在「設定 → 一般 → 版本更新」更新。Mimi 顯示下載進度，下載完成後即可安裝。Windows 安裝後會重新開啟 Mimi；macOS 和 Linux AppImage 可按「重新啟動並完成更新」。早於 v1.3.8 的版本需先手動安裝一次，之後才能在應用程式內更新。

自訂辨識的 WebSocket 範例、自動判定與語言提示的差異，以及各服務的語言範圍，見[語音服務與語言參數（簡體中文）](speech-language-setup.md#中文)。

### 平台支援

- macOS 13+（Apple 晶片與 Intel）：Apple 晶片選 `_aarch64.dmg`，Intel 選 `_x64.dmg`。v1.4.4 起提供 Intel 安裝包，已通過建置與簽署檢查，Intel 實機擷取和權限行為仍待驗證。DMG 未經 Apple 公證；首次開啟遭阻擋時，可在「系統設定 → 隱私權與安全性」選「仍要打開」。舊版更新時請留意下方權限說明。
- Windows x64：提供未簽署的預覽版 EXE／MSI，v1.4.3 起也提供可攜版 ZIP。SmartScreen 可能顯示提示。解壓縮 `mimi_<version>_x64-portable.zip` 後執行 `mimi.exe`。電腦須已安裝 WebView2（Windows 11 通常內建）。ZIP 不會將設定、認證資訊或匯出檔案搬到自身目錄；設定與私有認證檔案仍在應用程式的使用者目錄，匯出檔案保留在你選擇的位置。更新時先退出 Mimi，再以 Releases 的新版 ZIP 替換。可攜版不會執行應用程式內的安裝程式更新。
- Linux x86_64 預覽版（以 Ubuntu 22.04+ 為基線）：提供 `.deb` 和 AppImage。需要 PulseAudio，或啟用 `pipewire-pulse` 的 PipeWire、可用的預設輸出裝置，以及私有認證檔案的存取權限。系統音訊只使用輸出裝置的監聽來源。切換輸出裝置後請重新開始工作階段。建議使用 X11；Wayland 的定位、置頂與點擊穿透可能受桌面環境限制。請依 Mimi 設定中顯示的命令，在系統鍵盤設定中建立快捷鍵。沒有系統匣圖示時可從設定視窗操作；最小化會繼續執行，關閉設定視窗會退出 Mimi。暫不提供 Linux ARM64 安裝包。詳見 [Linux 安裝與驗證（英文）](development/linux.md)。

### macOS 系統音訊權限

macOS 14.2 及以上，新安裝擷取所有應用程式或指定應用程式時會要求僅系統音訊錄製權限。若想切換既有授權，先退出 Mimi，在「系統設定 → 隱私權與安全性」移除或關閉它的螢幕與系統音訊錄製授權，再開啟 Mimi 並啟動字幕，依提示允許僅系統音訊錄製，或在該分組中開啟 Mimi。系統要求重新啟動時請照做。切換是可選的，既有螢幕錄製授權仍可使用。未取得音訊權限時，可由錯誤提示開啟系統權限頁，授權並依提示重新啟動 Mimi 後再試。

### macOS 更新後重複授權

macOS 發布版本現已要求沿用同一張固定自簽憑證。v1.4.1 及更早版本使用隨建置變動的臨時簽署；首次更新至固定身分的版本時，可能需要重新授予一次錄製權限。原始碼修正不會改變已安裝的舊版。固定簽署排除了每次建置更換身分的原因，但不保證 macOS 永遠不再詢問授權。刪除本機簽署憑證不會改變已安裝應用程式的身分，也無法解決此問題。正式版請放在 `/Applications/mimi.app`，開發版使用 `/Applications/mimi-dev.app`。兩者各自保留簽署設定與錄製授權；開發版不能繼承正式版變更後的簽署身分。

錄製權限已開啟，卻仍提示無權限時，先退出並重新開啟 Mimi，依正常提示授權。仍無法擷取時：

1. 退出出現問題的應用程式。在「系統設定 → 隱私權與安全性 → 螢幕與系統音訊錄製」（名稱隨 macOS 版本而異），只移除對應的舊項目：正式版為 **mimi**，開發版為 **mimi-dev**。
2. 按 +，重新加入對應的 `/Applications/mimi.app` 或 `/Applications/mimi-dev.app` 並開啟權限。系統要求認證時由你本人完成；保留另一版本和其他應用程式的項目。
3. 重新開啟同一個應用程式，用快捷鍵或開始按鈕啟動字幕，播放有人聲的音訊，確認實際出現字幕。只有權限開關開啟，不代表已恢復。

這裡移除的是舊錄製授權，不是憑證或 API Key。嘗試一次仍未恢復時，請停止反覆重設，提供 macOS 版本、Mimi 版本、安裝來源與錯誤提示來[回報問題](https://github.com/yuxino/mimi/issues)，不要附上 API Key 或字幕內容。

舊系統認證資訊會自動遷移一次，確認私有明文檔案已儲存成功後才刪除原項目。遷移時可能要求讀取舊認證資訊的授權；完成後切換、儲存與更新均只使用本機檔案。檔案遺失或損毀也不會退回鑰匙圈。`codesign` 存取簽署私鑰的提示，是獨立的建置時提示。

## 服務設定

每個桌面服務設定都可記住辨識與翻譯語言組合。啟用設定並選好語言，再到「設定 → 語音與翻譯」開啟詳細設定，按「記住目前語言組合」。要修改或移除時，請明確按「更新為目前語言」或「取消綁定」。

切換或重新套用設定時，會恢復已儲存的組合；暫時更改語言不會覆寫它。系統匣與懸浮選單會在設定名稱下顯示已儲存的組合。按字幕頂部的服務資訊，可開啟目前設定的詳細內容。

## 音訊與儲存記錄

桌面版預設使用系統聲音，可在設定或懸浮控制中選擇系統聲音、麥克風，或同時開啟兩者。麥克風使用系統預設輸入裝置，實際開始擷取時才按需要求權限。雙路各自建立辨識連線、顯示字幕並產生服務用量。變更來源會關閉音訊錄製，需要時請在「儲存與匯出」重新開啟。

macOS 和 Windows build 20348+ 可透過應用程式選擇器，擷取指定應用程式的聲音。Linux 擷取系統輸出監聽通道，不提供此選擇器。

在「設定 → 儲存與匯出」選擇儲存字幕或錄製已選取的音訊來源。兩個開關預設關閉；開啟後隨工作階段寫入本機私有檔案，系統與麥克風音訊分開儲存。關閉選項會清空本次對應內容，已儲存的記錄需自行刪除。

開始下一次桌面工作階段時，會保留目前畫面內有數量限制的已確認字幕，按清空可移除。這不會開啟字幕儲存、把舊字幕複製到新記錄中，或在退出後恢復未儲存的字幕。

字幕最多保留 10,000 條已確認記錄／2 MiB 文字，音訊最多 64 MiB。達到上限會停止保留並提示。字幕時間戳是確認時間；WAV 不含暫停與重新連線的空白，兩者不能直接對齊。

## 字幕顯示

桌面版可在設定中選擇五種預設色塊（預設為白色），或按後方的自訂色塊開啟系統調色盤。系統聲音與麥克風分別設定顏色。預覽與懸浮字幕立即更新，沉浸模式同樣生效。雙語模式下，原文以較柔和的明暗層級與譯文區分。

字幕設定與懸浮控制中的「顯示時間」預設關閉。開啟後，兩個來源的已確認字幕旁都會顯示本機確認時間（HH:mm:ss），沉浸模式同樣生效。它表示確認時刻，不是說話起點。切回系統聲音後，保留的麥克風字幕仍帶來源圖示。懸浮控制也提供暫停／繼續。

在設定、懸浮控制或系統匣中選擇「僅譯文」、「原文＋譯文」或「僅原文」。macOS 用 ⌘⇧B，Windows／Linux X11 用 Ctrl+Shift+B 即時切換，不中斷翻譯。Wayland 請在系統設定中為 `mimi --cycle-subtitle-display` 綁定快捷鍵。雙語模式成對顯示已確認的原文與譯文，等待翻譯時先預覽辨識到的原文。

開啟「更早顯示字幕」時，懸浮窗會顯示仍可能修改的草稿；關閉後等待確認結果，連續說話可能需等待更久。此選項不會將草稿變成已儲存的歷史。

## 辨識錯誤

辨識失敗時，懸浮窗會保留已有字幕並持續顯示原因。展開懸浮控制可查看完整說明與復原操作。已識別的設定錯誤提供「語音與翻譯」入口，暫時連線或服務錯誤提供重試。修正或切換相關設定後，失敗的工作階段返回待機，不會自行開始擷取音訊；準備好後再開啟「即時字幕」。
