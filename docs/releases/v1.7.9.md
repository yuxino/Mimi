## English

- Fixed Gemini 2.5 Flash text translation compatibility on both desktop and Android: Mimi no longer sends `reasoning_effort: "none"` for `gemini-2.5-flash`, avoiding HTTP 400 errors once Google automatically routes `gemini-2.5-flash` traffic to `gemini-3.5-flash-lite` starting December 1, 2026 (`gemini-2.5-flash-lite` remains unchanged).
- Fixed click-through when dismissing the desktop subtitle control panel or its popups by clicking outside, preventing the dismissal click from accidentally triggering controls underneath.
- Fixed IME composition handling in desktop confirmation dialogs (such as session rename) so pressing Escape while composing preserves the draft instead of dismissing the dialog.
- Updated frontend dependency lockfiles and dev tooling, and extracted oversized inline Rust test modules without changing runtime behavior.

Update from Mimi or download the installer for your platform. This release also includes the signed Android APK. Validation covers automated desktop, shared-runtime, real JNI, and Android regressions, plus the prior live API verification against `gemini-3.5-flash-lite` and the public Gemini Live audio probe; physical Android devices and full multi-provider live sessions were not retested for this release.

## 中文

- 修复桌面端与 Android 端的 Gemini 2.5 Flash 文字翻译兼容问题：不再为 `gemini-2.5-flash` 附加 `reasoning_effort: "none"`，避免 Google 自 2026 年 12 月 1 日起将其自动路由至 `gemini-3.5-flash-lite` 后触发 HTTP 400 失败（未参与重定向的 `gemini-2.5-flash-lite` 保持不变）。
- 修复桌面端点击外部收起字幕控制面板或弹出菜单时的点击穿透问题，避免同一次点击误触发下层控件。
- 修复桌面端重命名等确认对话框在输入法组词期间按 Esc 误关弹窗的问题，保留当前输入草稿。
- 更新前端依赖锁文件与开发工具依赖，并拆分部分超大 Rust 内联测试模块（不改变运行时行为）。

可在 Mimi 内更新，或下载对应平台的安装包；本版同步提供签名的 Android 安装包。验证覆盖桌面端、共享层、真实 JNI 与 Android 自动回归，以及前期对 `gemini-3.5-flash-lite` 接口和 Gemini Live 公开样本的线上核验；未针对本版复测 Android 真机或全供应商实时长会话。
