## English

- Fixed a Linux X11 issue where clicking Pause in the subtitle overlay could start a window resize and miss the pause. The overlay's own edge and corner handles still resize the window.
- Linux loads the Settings view earlier during startup, making the live subtitles switch available sooner.

The Linux checks used `.deb` and AppImage packages in an isolated X11 desktop with a synthetic subtitle session. This release also includes an Android update, available from the More screen.

## 中文

- 修复 Linux X11 下点击字幕浮窗的暂停按钮可能被当成窗口缩放、导致暂停未生效的问题。仍可通过 Mimi 浮窗的边缘和角落调整窗口大小。
- Linux 启动时更早加载设置页，让实时字幕开关更快可用。

Linux 验收使用 `.deb` 和 AppImage，在隔离的 X11 桌面运行合成字幕会话。此版本也提供 Android 更新，可在「更多」页面检查更新。
