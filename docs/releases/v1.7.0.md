## English

- Android now shows the installed version in More and can check for updates. When a newer stable release is available, Download APK opens its official GitHub download in your browser; Android handles installation.
- Improved Android caption reading during accessibility scrolling and native input, and fixed saved-history filtering after lifecycle changes.
- Reduced saved-history memory use, idle interface work and audio encoding allocations. Android release packages now shrink unused code and resources.
- Text translation with `gpt-6.1-terra` now follows Mimi's existing low-latency, non-thinking policy on OpenAI and OpenRouter. Existing saved models and defaults are preserved.

Production-key short regressions covered eight configured provider routes, including speech before and after 90 seconds of silence. Some earlier direct-client requests had transport failures; successful reruns do not establish long-session reliability or a general translation-quality improvement. Android update checks are manual; this release does not add automatic downloading or installation.

## 中文

- Android 的「更多」页新增已安装版本和检查更新入口。发现较新的稳定版本后，「下载 APK」会在浏览器打开官方 GitHub 下载链接，由 Android 处理安装。
- 改善 Android 字幕在无障碍滚动及原生输入下的阅读稳定性，修复应用生命周期变化后的已保存历史筛选问题。
- 降低已保存历史的内存占用、空闲界面刷新和音频编码分配；Android 发布包会裁剪未使用的代码与资源。
- 使用 `gpt-6.1-terra` 进行文字翻译时，OpenAI 和 OpenRouter 现在遵循 Mimi 既有的低延迟、关闭思考策略。保留现有模型选择和默认值。

使用正式 Key 对八条已配置供应商路线完成了短回归，包括 90 秒静音前后的语音。此前部分直接客户端请求出现过传输失败，后续成功不代表长会话可靠性或整体翻译质量提升。Android 更新需要手动检查，本版本不提供自动下载或安装。
