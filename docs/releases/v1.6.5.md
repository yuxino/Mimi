## English

- Fixed cases where stopping subtitles kept an earlier draft instead of the latest recognized words, and reduced extra waiting when an Audio3 service does not signal completion.
- Reduced unnecessary work when displaying long Gemini subtitles and loading or saving session history.
- Reduced repeated saves when rapidly adjusting subtitle size or background opacity.
- Fixed saved-session lists when a session starts or finishes while the list is loading.
- Incomplete configurations remain visible in profile menus, with a reason shown and selection disabled until setup is complete.

Update from Settings → Software Update, or download the installer below. Portable Windows users can replace their existing executable after quitting Mimi.

Verified with automated tests. Live audio, real-provider sessions and physical devices were not revalidated.

Contributor: @yuxino.

## 中文

- 修复停止字幕时可能保留较早草稿、遗漏最新识别文字的问题，并减少 Audio3 服务未发送完成通知时的额外等待。
- 减少显示较长 Gemini 字幕，以及读取或保存历史记录时的不必要处理。
- 减少快速调整字幕字号或背景透明度时的重复保存。
- 修复记录列表加载期间启动或结束会话时，已保存记录显示不正确的问题。
- 配置未完成时，选择菜单会保留该配置并显示原因，补齐配置后才可选择。

可在「设置 → 软件更新」中更新，也可下载下方安装包。Windows 便携版请先退出 Mimi，再替换原有程序。

已通过自动化测试；本次未重新验证真实音频、实际服务会话和实体设备。
