## English

- Android captions now follow the latest text in long sentences and clear the previous sentence when a new one starts.
- Fixed Gemini sometimes losing the last caption when translation stops.
- Android shows the model currently in use. Stop translation before changing models.
- Switching immersive mode keeps the floating window's position and expanded view. Diagnostics is now under Advanced settings.

To update: desktop users can open Settings → General; Android users can install the new APK over the existing app. Unpack portable ZIP packages manually; `.deb` packages need manual installation.

Known limits: some Android apps block audio capture, and Baidu's silence-related session issue remains. macOS builds are not Apple-notarized.

## 中文

- 改善安卓字幕：长句会跟随最新文字，开始新句时不再停留在上一句。
- 修复 Gemini 停止翻译时偶尔丢失最后一句字幕的问题。
- 安卓端显示当前使用的模型；更换模型前需要先停止翻译。
- 切换沉浸模式时保留浮窗位置和展开状态；诊断入口移到高级设置。

更新方法：桌面端打开「设置 → 通用」；安卓端下载新 APK 覆盖安装。ZIP 包需手动解压，`.deb` 包需手动安装。

使用提示：部分安卓应用会禁止声音采集；百度在静音阶段仍有会话问题。macOS 版本尚未经过 Apple 公证。
