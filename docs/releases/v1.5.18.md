## English

- Android captions now follow the latest text in long sentences and clear the previous sentence when a new one starts.
- Fixed Gemini sometimes losing the last caption when translation stops.
- Android shows the model currently in use. Stop translation before changing models.
- Switching immersive mode keeps the floating window's position and expanded view. Diagnostics is now under Advanced settings.

To update: desktop users can open Settings → General; Android users can install the new APK over the existing app. Portable ZIP and `.deb` packages need manual installation.

Short Bilibili playback tests passed with several services on an Android emulator. Physical devices, long sessions, Intel Macs and desktop updates still need more testing. OpenAI testing was blocked by an empty account balance; Baidu's silence-related session issue remains. Some Android apps block audio capture. macOS builds are not Apple-notarized. [Detailed test results](https://github.com/yuxino/Mimi/pull/229).

## 中文

- 改善安卓字幕：长句会跟随最新文字，开始新句时不再停留在上一句。
- 修复 Gemini 停止翻译时偶尔丢失最后一句字幕的问题。
- 安卓端显示当前使用的模型；更换模型前需要先停止翻译。
- 切换沉浸模式时保留浮窗位置和展开状态；诊断入口移到高级设置。

更新方法：桌面端打开「设置 → 通用」；安卓端下载新 APK 覆盖安装。绿色 ZIP 和 `.deb` 包需手动安装。

已在安卓模拟器上用多家服务测试 B 站短时播放。真机、长时间使用、Intel Mac 和桌面更新仍需进一步验证。OpenAI 因账号余额不足未完成测试；百度在静音阶段的会话问题仍存在。部分安卓应用会禁止声音采集，macOS 版本尚未经过 Apple 公证。[详细测试结果](https://github.com/yuxino/Mimi/pull/229)。
