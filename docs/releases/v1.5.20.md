## English

- On macOS 14.2+, selected applications now support System Audio Recording Only. Existing screen recording grants continue to work.
- Clearer permission prompts and a button to open system privacy settings.
- Show only measured timings, removing stuck “Pending” labels and hiding stale values when paused or disconnected.
- Fix Grok source/translation pairing and improve Azure streaming captions and OpenAI error handling.

[Details](https://github.com/yuxino/Mimi/pull/235).

## 中文

- macOS 14.2 及以上，指定应用现已支持「仅系统录音」。已有录屏授权可继续使用。
- 权限提示更清楚，并提供直达系统权限设置的按钮。
- 耗时只显示实际测量结果，不再一直显示「待测」；暂停或断线时隐藏旧数据。
- 修复 Grok 原文与译文错配，改进 Azure 流式字幕和 OpenAI 错误处理。

[详情](https://github.com/yuxino/Mimi/pull/235)。
