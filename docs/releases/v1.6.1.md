## English

- Fixed a Windows crash when starting captions for a selected application.
- Fixed clipped caption controls at increased Windows display/text scaling and the panel title scrolling out of view on expansion.

Update from Settings → Software Update, or download the installer below. Portable Windows users can replace their existing executable after quitting Mimi.

Thanks to @LLLin000 for finding the causes, contributing the fixes, and testing them on Windows.

## 中文

- 修复 Windows 选择单个应用采集时，启动字幕导致程序崩溃的问题。
- 修复 Windows 提高显示或文字缩放后字幕控件被裁切，以及展开面板时标题被滚出视野的问题。

可在「设置 → 软件更新」中更新，也可下载下方安装包。Windows 便携版请先退出 Mimi，再替换原有程序。

感谢 @LLLin000 定位问题、提交修复并完成 Windows 实测。
