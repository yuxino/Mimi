## English

- Desktop subtitles show starting, pausing, and resuming feedback sooner. The first draft can appear immediately in an empty overlay. Resume becomes available after the previous session has released its resources.
- Fixed a timing issue where a second click at the previous Pause button position could open Settings after a provider configuration error. The error message still offers an explicit shortcut to the relevant settings.
- Windows opens the Settings view earlier during launch. Windows and Linux wait for native audio shutdown directly, reducing avoidable delay before capture can restart.
- Linux starts PulseAudio and PipeWire-Pulse capture sooner when using a compatible client library. X11 also spends less time registering shortcuts during app startup.

The performance changes are on desktop. Android is included in this release and can be updated by checking for updates on the More screen. Startup measurements used isolated native environments and synthetic inputs. First-caption latency with a live provider was outside these measurements.

## 中文

- 桌面字幕更快显示开启、暂停和继续的状态。浮窗为空时，第一条草稿可以立即显示。上一轮会话释放资源后，继续按钮即可使用。
- 修复供应商配置报错后，再点一次暂停按钮原位置可能打开设置的问题。错误提示仍提供明确入口，方便打开相应设置。
- Windows 启动时更早加载设置页。Windows 和 Linux 直接等待原生采音结束，减少重新开始采音前的等待。
- 使用兼容的客户端库时，Linux 的 PulseAudio 和 PipeWire-Pulse 采音就绪更快。X11 下启动应用时，注册快捷键的等待也更短。

本轮性能改动在桌面端。此版本同时提供 Android 安装包，可在「更多」页面手动检查更新。启动计时使用隔离的原生测试环境和合成输入，实测范围截至采音就绪或界面反馈。真实服务的首条字幕耗时仍待测量。
