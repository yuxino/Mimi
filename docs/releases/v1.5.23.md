## English

- Fixed an issue where brief system-audio capture delays on macOS could interrupt subtitles and reconnect the session. The fix applies to all services using the Core Audio capture backend.

Update to v1.5.23 through Mimi's update settings or download the installer below. macOS builds are not Apple-notarized.

## 中文

- 修复 macOS 系统音频捕获短暂延迟时，字幕可能中断并触发重连的问题。使用 Core Audio 捕获的服务均受益于此修复。

可在 Mimi 更新设置中升级至 v1.5.23，或下载下方安装包。macOS 安装包尚未经过 Apple 公证。
