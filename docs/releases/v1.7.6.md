## English

- Hover over the expanded desktop subtitle window to see “Translating” in the language button and the latest measured API round trip next to the right-hand tools. A second reading appears when the service provides a translation time. Narrow windows place the readings below the buttons. Moving the pointer away gives the space back to the subtitles.
- OpenAI Realtime and other streaming services now show translation activity as unfinished text arrives. Finishing the translation clears the label while the last measured timing stays visible on hover.

Update in Mimi or download the installer for your platform. This release also includes the signed Android APK.

## 中文

- 鼠标移入展开的桌面字幕窗，左上语言按钮会显示「翻译中」，右上工具栏旁可查看最近的接口延迟。支持单独计时的服务还会显示翻译耗时。窗口较窄时，数字排在按钮下方。移开鼠标后，空间会还给字幕。
- OpenAI Realtime 等实时服务逐步返回译文时，也能及时显示「翻译中」。译文完成后提示消失，鼠标留在字幕窗内仍能看到最近的延迟读数。

可在 Mimi 内更新，也可下载对应平台的安装包。本版同时提供签名的 Android APK。
