## English

- On Windows, drag a blank area of the expanded subtitle panel to move it. The panel stays open, and you can use the keyboard again as soon as you release the mouse.
- When choosing an app to capture audio from in Settings or the subtitle panel, refreshing the list keeps the same app highlighted. If that app closes before you press Enter, the list stays open so you can choose another.
- The signed Android APK also updates to 1.7.7. Both fixes apply to the desktop app.

## 中文

- 在 Windows 上，按住已展开字幕面板的空白处就能拖动面板。松开鼠标后面板保持展开，可以直接用键盘继续操作。
- 在设置或字幕面板里选择要采集声音的应用时，列表刷新会保留当前高亮的应用。如果它在确认前退出，按 Enter 后列表会保持展开，方便重新选择。
- 签名的 Android 安装包同步更新至 1.7.7。本次两项修复均适用于桌面端。
