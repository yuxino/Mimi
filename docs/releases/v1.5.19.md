## English

- On macOS 14.2+, capturing All Applications now supports System Audio Recording Only. Existing Screen & System Audio Recording grants continue to work without a separate audio-only grant.
- You can optionally switch to audio-only access: quit Mimi, remove or disable its old screen grant in System Settings, then reopen Mimi and allow system audio recording. Selected-application capture and macOS 13–14.1 still use the original permission.

Update in Settings → General, or download the package below. macOS builds are not Apple-notarized.

Thanks to @tsosunchia for reporting the permission issue. [Details and verification](https://github.com/yuxino/Mimi/pull/232).

## 中文

- macOS 14.2 及以上采集「全部应用」时，现已支持「仅系统录音」权限。之前授予的「录屏与系统录音」权限可以继续使用，无需另外授权。
- 也可以自行切换到仅系统录音：先退出 Mimi，在系统设置中移除或关闭旧录屏授权，再打开 Mimi 并允许系统录音。选择单个应用或使用 macOS 13–14.1 时，仍使用原来的权限。

更新方式：打开「设置 → 通用」，或下载下方安装包。macOS 版本尚未经过 Apple 公证。

感谢 @tsosunchia 反馈权限问题。[详情与验证](https://github.com/yuxino/Mimi/pull/232)。
