## English

- Fixed incomplete translations and withdrawn recognition drafts being saved as confirmed subtitles, and improved original/translation pairing.
- Kept unsaved names and retries across pages, protected new edits from late pastes, and retained Android drafts after interface recreation. Configurations missing required credentials or setup can no longer be selected.
- Improved local credential migration and configuration loading, including recovery after interrupted operations.
- Protected desktop saved-session deletion and recording finalization. Changing Windows audio sources now clears the recording opt-in.
- Improved macOS language detection, including regional variants.

Update from Settings → Software Update, or download the installer below. Portable Windows users can replace their existing executable after quitting Mimi.

## 中文

- 修复不完整译文、已撤回的识别草稿被保存为确认字幕的问题，改善原文与译文配对。
- 切换页面时保留未保存的名称和重试入口，迟到的粘贴不再覆盖新输入；Android 界面重建后保留草稿。缺少凭据或必要设置的配置无法再被选中。
- 改善本地凭据迁移和配置加载，包括中断后的恢复。
- 保护桌面版已保存会话的删除和录音收尾。Windows 切换音频来源时会清除录音勾选。
- 改善 macOS 系统语言识别，包括地区变体。

可在「设置 → 软件更新」中更新，也可下载下方安装包。Windows 便携版请先退出 Mimi，再替换原有程序。
