## English

- Added batch deletion for saved sessions on both desktop and Android: switch into Select mode to pick multiple sessions, use Select all / Deselect all (scoped to the current search and filter on desktop), or use Clear all to remove all saved sessions at once.
- Active/current sessions remain protected from batch deletion, every bulk delete confirms the exact session count, and partial storage failures keep only the failed items for retry.
- Thanks to @yeshuoer for suggesting batch deletion in [#416](https://github.com/yuxino/Mimi/issues/416).

Update from Mimi or download the installer for your platform. This release also includes the signed Android APK. Validation covers automated desktop/shared/JNI/Android regressions and browser UI layout review; physical Android device and live-provider sessions were not retested for this release.

## 中文

- 桌面端与 Android 端均新增已保存会话批量删除功能：点击「选择」即可多选会话，支持「全选 / 取消全选」（桌面端仅作用于当前搜索与筛选结果），也支持直接「全部清空」已保存会话。
- 正在进行或当前的会话不会被批量删除误删；每次批量删除都会弹出包含精确数量的确认对话框，若出现部分文件删除失败会保留失败项以便重试。
- 感谢 @yeshuoer 在 [#416](https://github.com/yuxino/Mimi/issues/416) 提出该功能建议。

可在 Mimi 内更新，或下载对应平台的安装包；本版同步提供签名的 Android 安装包。验证覆盖桌面端、共享层、真实 JNI 与 Android 自动回归及浏览器界面排版检查，未针对本版复测 Android 真机或实时供应商长会话。
