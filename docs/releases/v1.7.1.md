## English

- Fixed Gemini ASR+MT rejecting valid binary JSON setup and transcription messages. Standalone voice-activity notifications no longer interrupt recognition.
- Existing binary JSON routes for Alibaba Cloud, Gemini Live, OpenAI Realtime and Azure Realtime now reject corrupted UTF-8 instead of displaying replacement characters as captions.
- Fixed Android retrying explicit protocol/setup rejections from Gemini ASR, xAI STT and custom recognition as network failures. Desktop connection checks distinguish incompatible recognition responses from service rejection.

The fixes share the same Rust runtime on desktop and Android. Regression coverage uses synthetic WebSocket/JNI fixtures; it does not establish live-provider availability or a general translation-quality improvement. Provider models and saved settings are unchanged.

Thanks to @1665893651-star for diagnosing the Gemini binary-frame failure, supplying the fix and verifying it on Windows.
