## Установка и обновление

1. Скачайте из [последнего релиза](https://github.com/yuxino/mimi/releases/latest) DMG для macOS на Apple silicon или Intel, EXE, MSI или переносимый ZIP для Windows x64 либо .deb / AppImage для Linux x86_64. Вы также можете собрать приложение из исходного кода.
2. Откройте «Настройки → Модели и сервисы», добавьте конфигурацию, введите запрошенные учётные данные поставщика и сохраните. Выберите языки распознавания и перевода.
3. Запустите воспроизведение и включите «Субтитры в реальном времени» в разделе «Субтитры». Их также можно запустить из системного меню значка mimi в строке меню или системном трее. В macOS 14.2+ при захвате звука всех приложений или выбранного приложения поддерживается режим «Только запись системного звука». Существующие разрешения на запись экрана используются повторно, без запроса отдельного разрешения только на звук. В macOS 13–14.1 требуется разрешение «Запись экрана и системного звука».

Значок mimi в системном трее открывает системное меню для запуска и остановки субтитров, выбора режима отображения, настроек и выхода; в macOS также доступен пункт «Показывать в Dock». Сервисы, языки, блокировка и иммерсивный режим настраиваются в разделе «Настройки». На поддерживаемых Mac можно бесплатно использовать локальное распознавание речи Apple без API-ключа; подготовьте языковые ресурсы и отдельно выберите перевод текста.

Для облачных сервисов требуются собственные учётные данные для API поставщика; использование может быть платным. Учётные данные настольной версии хранятся в приватном текстовом файле без шифрования, защищённом правами доступа локальной файловой системы.

В macOS, установочных копиях для Windows и Linux AppImage откройте «Настройки → Основные → Обновление ПО». Mimi загружает обновление с индикацией прогресса, после чего предлагает установить его. Windows повторно открывает Mimi после установки; в macOS и Linux AppImage доступно отдельное действие «Перезапустить и завершить обновление».
В версиях ниже v1.3.8 необходимо один раз установить обновление вручную, чтобы включить обновления внутри приложения.

Примеры WebSocket для пользовательских сервисов, различия между автоматическим определением и языковыми подсказками, а также актуальный диапазон языков каждой интеграции описаны в [настройке речевых сервисов и языковых параметров (на английском)](speech-language-setup.md#english).

### Поддерживаемые платформы

- macOS 13+ (Apple silicon и Intel): выберите `_aarch64.dmg` для Apple silicon или `_x64.dmg` для Intel. Пакеты для Intel доступны начиная с v1.4.4; сборка и подпись проверены, но захват звука и поведение разрешений на оборудовании Intel пока не проверены. Установщики DMG не нотаризованы Apple. Если первый запуск заблокирован, выберите «Всё равно открыть» в «Системных настройках → Конфиденциальность и безопасность». При обновлении старой сборки ознакомьтесь с примечаниями о разрешениях ниже.
- Windows x64: доступны неподписанные предварительные установщики EXE / MSI и, начиная с v1.4.3, переносимый ZIP; SmartScreen может показать предупреждение. Распакуйте `mimi_<version>_x64-portable.zip` и запустите `mimi.exe` без установки. WebView2 должен быть установлен заранее (обычно он уже есть в Windows 11). ZIP не перемещает настройки, учётные данные сервисов или экспортированные файлы в свою папку: настройки и приватные файлы учётных данных остаются в пользовательском каталоге приложения, а экспортированные файлы — в выбранном вами месте. Чтобы обновить эту копию, закройте Mimi и замените её файлами из нового ZIP на странице Releases. Переносимая сборка не запускает установщик обновлений внутри приложения.

- Предварительная версия для Linux x86_64 (базовая система — Ubuntu 22.04+): используйте пакет `.deb` или AppImage. Требуются PulseAudio или PipeWire с `pipewire-pulse`, работающее устройство вывода по умолчанию и доступ к приватному локальному файлу учётных данных. По умолчанию системный звук захватывается с монитора текущего устройства вывода; также можно выбрать один поток воспроизведения. После смены устройства вывода по умолчанию перезапустите сеанс. Рекомендуется X11; композиторы Wayland могут ограничивать позиционирование, отображение поверх других окон и пропуск нажатий. Для сочетаний клавиш Wayland создайте системные сочетания с командами, показанными в настройках. Если на рабочем столе нет значка в системном трее, используйте окно настроек. Сверните его, чтобы субтитры продолжали работать; закрытие окна в Linux завершает Mimi. Пакеты Linux ARM64 не предоставляются. См. [настройку и проверку Linux (на английском)](development/linux.md).

### Разрешения на запись системного звука в macOS

В macOS 14.2+ при выборе всех приложений или отдельных приложений новые установки запрашивают разрешение «Только запись системного звука». Чтобы изменить режим в существующей установке, закройте Mimi, удалите или отключите его запись в разделе «Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука», затем снова откройте Mimi и запустите субтитры. При запросе разрешите «Только запись системного звука» или включите Mimi в соответствующем разделе. Перезапустите Mimi, если macOS этого потребует. Переключение необязательно: существующее разрешение на запись экрана продолжает работать. Если разрешение на звук отсутствует, откройте системную страницу конфиденциальности из сообщения об ошибке, разрешите доступ Mimi, выполните инструкции системы по перезапуску и повторите попытку.

### Разрешения macOS после обновления

Процесс выпуска теперь требует использовать один фиксированный самоподписанный сертификат во всех сборках macOS. В предыдущих релизах до v1.4.1 использовались ad-hoc-подписи, которые менялись с каждой сборкой; при установке первого релиза с фиксированной идентичностью может потребоваться повторно предоставить разрешение на запись. Это изменение исходного кода не затрагивает уже установленное приложение. Фиксированная подпись предотвращает смену идентичности между сборками, но не гарантирует, что macOS никогда снова не запросит согласие. Удаление локального сертификата подписи не меняет идентичность установленного приложения и не решает эту проблему. Храните релизное приложение в `/Applications/mimi.app`, а для разработки используйте `/Applications/mimi-dev.app`. Каждое приложение сохраняет собственную закреплённую подпись и разрешение на запись; сборка для разработки не должна наследовать изменённую идентичность релизного приложения.

Если запись разрешена, но Mimi по-прежнему сообщает об отказе в доступе, сначала закройте и снова откройте Mimi, а затем следуйте обычному запросу разрешения. Если захват по-прежнему запрещён:

1. Закройте нужное приложение. В «Системных настройках → Конфиденциальность и безопасность → Запись экрана и системного звука» (название зависит от версии macOS) выберите и удалите только его старую запись: **mimi** для релизного приложения или **mimi-dev** для разработки.
2. Нажмите + и добавьте соответствующее приложение `/Applications/mimi.app` или `/Applications/mimi-dev.app`, включите его разрешение и самостоятельно пройдите системную аутентификацию. Не изменяйте другое приложение Mimi и посторонние записи.
3. Снова откройте то же приложение, запустите субтитры сочетанием клавиш или кнопкой «Пуск» и включите аудио с речью, чтобы убедиться, что субтитры действительно появляются. Одного включённого переключателя недостаточно для подтверждения восстановления.

Так удаляется старое разрешение на запись, а не сертификат или API-ключ. Если одна попытка не помогла, не повторяйте сброс многократно и [сообщите об ошибке](https://github.com/yuxino/mimi/issues), указав версии macOS и Mimi, а также источник установки. Не включайте API-ключи или содержимое субтитров.

Учётные данные настольной версии хранятся в приватном текстовом файле без шифрования, защищённом правами доступа к файлу. Существующие учётные данные ОС автоматически импортируются один раз и удаляются после проверки сохранённой копии. Для импорта может потребоваться разрешение на доступ к старому хранилищу; после его завершения переключение, сохранение и обновление используют только файл. При отсутствии или повреждении локальных учётных данных возврата к Keychain не происходит. Запрос `codesign` на доступ к закрытому ключу подписи — отдельный запрос, возникающий во время сборки.

## Конфигурации сервисов

Каждая конфигурация сервиса на компьютере может запоминать пару языков распознавания и перевода. Активируйте конфигурацию и выберите языки, затем откройте её сведения в «Настройки → Модели и сервисы» и нажмите **Запомнить текущие языки**. Чтобы изменить или удалить сохранённую пару, явно выберите **Обновить до текущих языков** или **Удалить сохранённую пару**.

При переключении на конфигурацию или её повторном применении сохранённая пара восстанавливается. Временные изменения языков не перезаписывают её. Плавающая панель управления показывает сохранённую пару под именем конфигурации. Нажмите на информацию о сервисе в заголовке субтитров, чтобы открыть сведения о текущей конфигурации.

## Аудио и сохранённые сеансы

На компьютере по умолчанию используется системный звук. В настройках или на плавающей панели выберите системный звук, микрофон или оба источника. Захват с микрофона использует системный микрофон по умолчанию и при необходимости запрашивает разрешение при начале захвата. При выборе обоих источников у каждого входа есть собственное соединение распознавания, субтитры и расход ресурсов сервиса. Изменение входов отключает запись звука; при необходимости включите её снова в разделе «Сохранение и экспорт».

В macOS и Windows build 20348+ используйте средство выбора приложения, чтобы переводить звук выбранного приложения. В Linux то же средство выбирает один поток воспроизведения, отображаемый как «имя приложения · имя потока». Если поток отсутствует, начните воспроизведение и обновите список; потоки одного приложения отображаются как отдельные варианты.

В разделе «Настройки → Сохранение и экспорт» выберите, нужно ли сохранять субтитры или записывать выбранные аудиовходы. Оба переключателя по умолчанию отключены. При включении содержимое постепенно записывается в приватные локальные файлы сеанса; системный звук и звук микрофона остаются раздельными. Отключение параметра очищает его содержимое текущего сеанса; сохранённые сеансы удаляются только явным действием.

Находите сохранённые сеансы по имени или фильтруйте сеансы с текстом либо аудио. Выберите сеанс, чтобы открыть режим чтения; кнопка «Назад» восстанавливает позицию в списке. Можно искать по оригиналу и переводу, читать любой язык или оба и копировать отдельные фрагменты. В режиме чтения доступны «Экспорт» и «Ещё»; в меню «Ещё» находятся действия «Переименовать» и «Удалить» для сохранённых сеансов.

С помощью «Экспорта» выберите доступный формат TXT, Markdown или WAV. Текстовый экспорт включает весь выбранный сеанс независимо от результатов поиска: оригинал, перевод или оба, при желании с отметками времени подтверждения. Для WAV выберите источник звука, если записаны оба. Сохранённые сеансы можно экспортировать во время работы субтитров в реальном времени; перед экспортом текущего сеанса остановите субтитры в реальном времени.

Остановите субтитры в реальном времени перед воспроизведением записи. Нажмите «Воспроизвести» в режиме чтения, чтобы загрузить и воспроизвести звук, затем поставьте на паузу, проверьте прошедшее и общее время или перетащите ползунок для перехода к нужному месту. При ошибке загрузки или воспроизведения повторите попытку. Остановленный текущий сеанс также может воспроизводить ещё доступный звук; при штатной остановке он обычно перемещается в список сохранённых сеансов.

При запуске следующего сеанса на компьютере ограниченный набор подтверждённых субтитров остаётся на экране. «Очистить» удаляет их. Это не включает сохранение расшифровки, не копирует старые строки в сохранённую расшифровку нового сеанса и не восстанавливает несохранённые субтитры после выхода из приложения.

Хранение расшифровки ограничено 10 000 подтверждённых пар / 2 МиБ текста, а аудио — 64 МиБ. При достижении предела сохранение прекращается и появляется уведомление. Отметки времени расшифровки указывают момент подтверждения; WAV не содержит пауз и перерывов при повторном подключении, поэтому эти данные не синхронизированы.

## Отображение субтитров

Выберите язык интерфейса настольной версии в «Настройки → Основные»: упрощённый китайский, традиционный китайский, английский, японский, немецкий, корейский, французский, тайский или русский. Вариант «Системный» следует языку системы; смена языка интерфейса не сбрасывает текущие правки и состояние субтитров. Языки распознавания и перевода выбираются отдельно.

В настройках выберите один из пяти цветовых образцов субтитров (по умолчанию белый) или используйте следующий за ними пользовательский образец, чтобы открыть системный выбор цвета. Для системного звука и микрофона предусмотрены отдельные настройки цвета. Предпросмотр и плавающие субтитры обновляются сразу, в том числе в иммерсивном режиме. В двуязычном режиме оригинал визуально приглушён по сравнению с переводом.

Параметр «Показывать время» доступен в настройках субтитров и на плавающей панели и по умолчанию отключён. При включении рядом с подтверждёнными субтитрами из системного звука и микрофона отображается локальное время подтверждения (HH:mm:ss), в том числе в иммерсивном режиме. Оно указывает момент подтверждения субтитра, а не начало речи. При обратном переключении на системный звук у уже отображаемых строк микрофона остаётся небольшой значок источника. Плавающая панель также позволяет ставить субтитры на паузу и возобновлять их.

Выберите «Только перевод», «Оригинал + перевод» или «Только оригинал» в настройках, на панели управления оверлеем или в системном трее. Мгновенно переключайтесь сочетанием ⌘⇧B в macOS или Ctrl+Shift+B в Windows/Linux X11. В Wayland назначьте `mimi --cycle-subtitle-display` в настройках рабочего стола. Режим отображения меняется без перезапуска перевода. В двуязычном режиме подтверждённые предложения объединяются в пары, а пока перевод ожидается, отображается предварительный распознанный оригинал.

Если включён параметр «Показывать субтитры раньше», оверлей отображает черновики, которые ещё могут измениться. Отключите его, чтобы ждать подтверждённых результатов; при непрерывной речи появление субтитров может занять больше времени. Этот выбор отображения не превращает черновик в сохранённую историю.

## Ошибки распознавания

Ошибки распознавания остаются видимыми в окне субтитров рядом с существующими субтитрами. Откройте плавающую панель управления, чтобы увидеть полное объяснение и действия для восстановления. При обнаруженной ошибке конфигурации предлагается открыть «Модели и сервисы»; при временных ошибках соединения или сервиса — «Повторить». Исправление или смена затронутой конфигурации переводит сеанс с ошибкой в состояние ожидания без запуска аудио. Когда будете готовы, снова запустите субтитры в реальном времени.

В разделе «Настройки → Диагностика» отображается снимок состояния аудиовхода, перевода, последних измерений и событий, а также ссылки на соответствующие настройки. Обновите его или скопируйте отчёт для отзыва на GitHub, предварительно проверив содержимое. Отчёты не содержат учётных данных и текста субтитров. Эти наблюдения не устанавливают причину: количество событий не равно количеству предложений, а измерения не показывают общую задержку субтитров.
