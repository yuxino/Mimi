# วิธีใช้ Mimi

[กลับไปที่ README](readme/th.md)

ลิงก์เปิดใช้บริการ ช่องข้อมูลรับรอง และโมเดลปัจจุบัน ดูได้ใน [คู่มือตั้งค่าผู้ให้บริการ (ภาษาอังกฤษ)](provider-setup.md)

เลือกภาษาอินเทอร์เฟซใน การตั้งค่า → ทั่วไป มีจีนตัวย่อ จีนตัวเต็ม อังกฤษ ญี่ปุ่น เยอรมัน เกาหลี ฝรั่งเศส และไทย ตัวเลือกตามระบบจะใช้ภาษาของระบบ การเปลี่ยนภาษาไม่ล้างข้อมูลที่กำลังแก้ไขหรือสถานะคำบรรยาย ต้องเลือกภาษารู้จำเสียงและภาษาแปลแยกกัน

## ติดตั้งและอัปเดต

1. ดาวน์โหลด DMG สำหรับ macOS ชิป Apple หรือ Intel, EXE / MSI / ZIP แบบพกพาสำหรับ Windows x64 หรือ .deb / AppImage สำหรับ Linux x86_64 จาก [รุ่นล่าสุด](https://github.com/yuxino/mimi/releases/latest) หรือบิลด์จากซอร์ส
2. เปิด การตั้งค่า → เสียงและการแปล เพิ่มการตั้งค่า ใส่ข้อมูลรับรองตามที่บริการต้องการ แล้วบันทึก เลือกภาษารู้จำเสียงและภาษาแปล
3. เล่นเสียง แล้วเปิดคำบรรยายสดในหน้าคำบรรยาย หรือเริ่มจากไอคอน mimi ในแถบเมนูหรือถาดระบบ บน macOS 14.2 ขึ้นไป ทั้งทุกแอปและแอปที่เลือกใช้สิทธิ์บันทึกเฉพาะเสียงระบบได้ สิทธิ์บันทึกหน้าจอเดิมจะถูกใช้ต่อโดยไม่ขอสิทธิ์เสียงเพิ่มเติม macOS 13–14.1 ต้องใช้สิทธิ์บันทึกหน้าจอและเสียงระบบ

ต้องเตรียมข้อมูลรับรอง API ของคุณเอง การใช้บริการอาจมีค่าใช้จ่าย ข้อมูลรับรองบนเดสก์ท็อปเก็บในไฟล์ข้อความธรรมดาส่วนตัวบนเครื่องซึ่งป้องกันด้วยสิทธิ์เข้าถึงไฟล์

macOS, Windows รุ่นติดตั้ง และ Linux AppImage อัปเดตได้จาก การตั้งค่า → ทั่วไป → อัปเดตซอฟต์แวร์ Mimi แสดงความคืบหน้าการดาวน์โหลด แล้วให้ติดตั้งเมื่อเสร็จ Windows จะเปิด Mimi อีกครั้งหลังติดตั้ง ส่วน macOS และ Linux AppImage มีปุ่มเริ่มใหม่เพื่อจบการอัปเดต รุ่นก่อน v1.3.8 ต้องติดตั้งด้วยตนเองหนึ่งครั้งก่อนใช้การอัปเดตในแอป

ตัวอย่าง WebSocket ของบริการกำหนดเอง ความต่างระหว่างตรวจจับภาษาอัตโนมัติกับคำใบ้ภาษา และขอบเขตภาษาของแต่ละบริการ ดู [การตั้งค่าบริการเสียงและภาษา (ภาษาอังกฤษ)](speech-language-setup.md#english)

### แพลตฟอร์มที่รองรับ

- macOS 13 ขึ้นไป (ชิป Apple และ Intel): เลือก `_aarch64.dmg` สำหรับชิป Apple หรือ `_x64.dmg` สำหรับ Intel มีแพ็กเกจ Intel ตั้งแต่ v1.4.4 ผ่านการตรวจบิลด์และลายเซ็นแล้ว แต่การจับเสียงและสิทธิ์บนเครื่อง Intel จริงยังไม่ได้ยืนยัน DMG ยังไม่ผ่านการรับรอง notarization จาก Apple หากเปิดครั้งแรกถูกบล็อก ให้เลือกเปิดต่อใน การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย เมื่ออัปเดตจากรุ่นเก่า อ่านคำแนะนำสิทธิ์ด้านล่าง
- Windows x64: มี EXE / MSI รุ่นตัวอย่างที่ไม่ได้ลงลายเซ็น และ ZIP แบบพกพาตั้งแต่ v1.4.3 SmartScreen อาจเตือน แตกไฟล์ `mimi_<version>_x64-portable.zip` แล้วเปิด `mimi.exe` ต้องมี WebView2 อยู่แล้ว (Windows 11 มักมีให้) การตั้งค่าและไฟล์ข้อมูลรับรองส่วนตัวอยู่ในไดเรกทอรีผู้ใช้ของแอป ไฟล์ส่งออกอยู่ในตำแหน่งที่เลือก ZIP ไม่ย้ายสิ่งเหล่านี้เข้าโฟลเดอร์ของมัน อัปเดตโดยออกจาก Mimi แล้วแทนที่ด้วย ZIP ใหม่จาก Releases รุ่นพกพาไม่ใช้ตัวติดตั้งอัปเดตในแอป
- Linux x86_64 รุ่นตัวอย่าง (ใช้ Ubuntu 22.04 ขึ้นไปเป็นฐาน): มี `.deb` และ AppImage ต้องมี PulseAudio หรือ PipeWire ที่เปิด `pipewire-pulse`, อุปกรณ์เอาต์พุตเริ่มต้นที่ใช้งานได้ และสิทธิ์อ่านไฟล์ข้อมูลรับรองส่วนตัว เสียงระบบใช้เฉพาะแหล่งมอนิเตอร์ของเอาต์พุต เปลี่ยนอุปกรณ์แล้วต้องเริ่มเซสชันใหม่ แนะนำ X11 บน Wayland การวางตำแหน่ง อยู่ด้านบน และให้คลิกผ่านอาจถูกจำกัดตามเดสก์ท็อป ใช้คำสั่งที่ Mimi แสดงเพื่อตั้งปุ่มลัดในระบบ หากไม่มีไอคอนถาดระบบให้ใช้หน้าการตั้งค่า การย่อหน้าต่างจะทำงานต่อ แต่ปิดหน้าการตั้งค่าจะออกจาก Mimi บน Linux ยังไม่มีแพ็กเกจ Linux ARM64 ดู [ติดตั้งและตรวจสอบ Linux (ภาษาอังกฤษ)](development/linux.md)

### สิทธิ์เสียงระบบบน macOS

การติดตั้งใหม่บน macOS 14.2 ขึ้นไปจะขอสิทธิ์บันทึกเฉพาะเสียงระบบทั้งสำหรับทุกแอปและแอปที่เลือก หากต้องการเปลี่ยนสิทธิ์เดิม ให้ออกจาก Mimi แล้วลบหรือปิดรายการสิทธิ์บันทึกหน้าจอและเสียงระบบของ Mimi ใน การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย จากนั้นเปิด Mimi และเริ่มคำบรรยาย อนุญาตบันทึกเฉพาะเสียงระบบเมื่อถาม หรือเปิด Mimi ในหมวดนั้น หากระบบให้เริ่มแอปใหม่ให้ทำตาม การเปลี่ยนเป็นทางเลือก สิทธิ์บันทึกหน้าจอเดิมยังใช้ได้ หากไม่มีสิทธิ์ เปิดหน้าสิทธิ์ระบบจากข้อความผิดพลาด อนุญาตและเริ่มใหม่ตามที่ระบบขอ แล้วลองอีกครั้ง

### macOS ขอสิทธิ์ซ้ำหลังอัปเดต

รุ่น macOS ที่เผยแพร่ปัจจุบันใช้ใบรับรองลงนามด้วยตนเองใบเดิมคงที่ รุ่น v1.4.1 และก่อนหน้าใช้ลายเซ็นชั่วคราวที่เปลี่ยนทุกบิลด์ การอัปเดตครั้งแรกไปยังตัวตนคงที่อาจต้องให้สิทธิ์บันทึกอีกครั้ง การแก้ซอร์สไม่เปลี่ยนแอปเก่าที่ติดตั้งแล้ว ลายเซ็นคงที่ป้องกันตัวตนเปลี่ยนทุกบิลด์ แต่ไม่รับประกันว่า macOS จะไม่ถามอีก การลบใบรับรองบนเครื่องไม่เปลี่ยนตัวตนแอปที่ติดตั้งและไม่แก้ปัญหานี้ ใช้ `/Applications/mimi.app` สำหรับรุ่นเผยแพร่ และ `/Applications/mimi-dev.app` สำหรับพัฒนา ทั้งสองมีการตั้งค่าลายเซ็นและสิทธิ์บันทึกแยกกัน รุ่นพัฒนาไม่รับตัวตนลายเซ็นที่เปลี่ยนของรุ่นเผยแพร่

หากเปิดสิทธิ์แล้วแต่จับเสียงไม่ได้ ให้ออกจาก Mimi แล้วเปิดใหม่และทำตามคำขอสิทธิ์ปกติก่อน หากยังไม่ได้:

1. ออกจากแอปที่มีปัญหา ใน การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การบันทึกหน้าจอและเสียงระบบ (ชื่ออาจต่างตามรุ่น macOS) ลบเฉพาะรายการเก่าของแอปนั้น รุ่นเผยแพร่คือ **mimi** รุ่นพัฒนาคือ **mimi-dev**
2. กด + เพิ่ม `/Applications/mimi.app` หรือ `/Applications/mimi-dev.app` ที่ตรงกัน แล้วเปิดสิทธิ์ ยืนยันตัวตนระบบด้วยตัวเอง เก็บรายการ Mimi อีกเวอร์ชันและแอปอื่นไว้
3. เปิดแอปเดิม เริ่มคำบรรยายด้วยปุ่มลัดหรือปุ่มเริ่ม แล้วเล่นเสียงที่มีคนพูด ตรวจว่ามีคำบรรยายจริง การเปิดสวิตช์สิทธิ์อย่างเดียวไม่ยืนยันว่ากลับมาใช้งานได้

สิ่งที่ลบคือสิทธิ์บันทึกเก่า ไม่ใช่ใบรับรองหรือ API Key หากลองหนึ่งครั้งแล้วยังไม่ได้ อย่ารีเซ็ตซ้ำ ให้ [รายงานปัญหา](https://github.com/yuxino/mimi/issues) พร้อมรุ่น macOS และ Mimi แหล่งติดตั้ง และข้อความผิดพลาด โดยไม่แนบ API Key หรือเนื้อหาคำบรรยาย

ข้อมูลรับรองเก่าของระบบจะนำเข้าอัตโนมัติครั้งเดียว แล้วลบรายการเดิมหลังตรวจว่าไฟล์ข้อความธรรมดาส่วนตัวบันทึกสำเร็จ การนำเข้าอาจขอสิทธิ์อ่านข้อมูลเก่า หลังจากนั้นการสลับ บันทึก และอัปเดตจะใช้เฉพาะไฟล์ ไฟล์หายหรือเสียหายจะไม่ย้อนกลับไปใช้ Keychain คำขอ `codesign` เพื่อเข้าถึงคีย์ส่วนตัวสำหรับลงลายเซ็นเป็นคำขอแยกขณะบิลด์

## การตั้งค่าบริการ

แต่ละการตั้งค่าบริการบนเดสก์ท็อปจำคู่ภาษารู้จำและภาษาแปลได้ เปิดใช้การตั้งค่าและเลือกภาษา จากนั้นเปิดรายละเอียดใน การตั้งค่า → เสียงและการแปล แล้วเลือก **จดจำภาษาปัจจุบัน** หากต้องการเปลี่ยนหรือลบคู่ภาษา ให้เลือก **อัปเดตเป็นภาษาปัจจุบัน** หรือ **ลบคู่ภาษาที่บันทึกไว้** ด้วยตัวเอง

การสลับหรือใช้การตั้งค่าเดิมอีกครั้งจะคืนคู่ภาษาที่บันทึก การเปลี่ยนภาษาชั่วคราวไม่เขียนทับคู่นั้น เมนูถาดระบบและเมนูลอยแสดงคู่ภาษาด้านล่างชื่อการตั้งค่า คลิกข้อมูลบริการด้านบนคำบรรยายเพื่อเปิดรายละเอียดปัจจุบัน

## เสียงและเซสชันที่บันทึก

เดสก์ท็อปใช้เสียงระบบเป็นค่าเริ่มต้น เลือกเสียงระบบ ไมโครโฟน หรือทั้งสองจากการตั้งค่าหรือแผงควบคุมลอย ไมโครโฟนใช้อุปกรณ์เริ่มต้นของระบบและขอสิทธิ์เมื่อเริ่มจับเสียงจริงตามความจำเป็น ทั้งสองแหล่งมีการเชื่อมต่อรู้จำ คำบรรยาย และปริมาณใช้บริการแยกกัน เปลี่ยนแหล่งเสียงแล้วการบันทึกจะปิด หากต้องการให้เปิดอีกครั้งใน บันทึกและส่งออก

macOS และ Windows build 20348 ขึ้นไปมีตัวเลือกแอปเพื่อจับเสียงจากแอปที่เลือก Linux จับมอนิเตอร์เอาต์พุตระบบและไม่มีตัวเลือกนี้

ใน การตั้งค่า → บันทึกและส่งออก เลือกเก็บคำบรรยายหรือบันทึกแหล่งเสียงที่เลือก ทั้งสองปิดไว้เป็นค่าเริ่มต้น เมื่อเปิด เนื้อหาจะทยอยเขียนลงไฟล์เซสชันส่วนตัวบนเครื่อง โดยเสียงระบบกับไมโครโฟนแยกไฟล์กัน ปิดตัวเลือกแล้วเนื้อหาที่เกี่ยวข้องของเซสชันปัจจุบันจะถูกล้าง เซสชันที่บันทึกไว้แล้วต้องลบอย่างชัดเจน

เริ่มเซสชันถัดไปแล้วคำบรรยายที่ยืนยันและอยู่ในจำนวนจำกัดบนหน้าจอจะยังอยู่ ใช้ล้างเพื่อนำออก การทำเช่นนี้ไม่เปิดการเก็บคำบรรยาย ไม่คัดลอกข้อความเก่าเข้าเซสชันใหม่ และไม่คืนคำบรรยายที่ไม่ได้บันทึกหลังออกจากแอป

คำบรรยายเก็บได้ไม่เกิน 10,000 คู่ที่ยืนยัน / ข้อความ 2 MiB และเสียงไม่เกิน 64 MiB ถึงขีดจำกัดแล้วจะหยุดเก็บและแจ้งเตือน เวลาคำบรรยายเป็นเวลายืนยัน ส่วน WAV ไม่รวมช่วงหยุดและช่วงเชื่อมต่อใหม่ จึงเทียบเวลาโดยตรงไม่ได้

## การแสดงคำบรรยาย

เลือกจากห้าสีในหน้าการตั้งค่า (ค่าเริ่มต้นสีขาว) หรือใช้ช่องสีที่กำหนดเองด้านหลังเพื่อเปิดตัวเลือกสีระบบ เสียงระบบและไมโครโฟนตั้งสีแยกกัน ตัวอย่างและคำบรรยายลอยเปลี่ยนทันที รวมถึงโหมดเต็มอรรถรส ในโหมดสองภาษา ต้นฉบับใช้ระดับความสว่างที่นุ่มกว่าคำแปล

แสดงเวลาอยู่ในหน้าคำบรรยายและแผงควบคุมลอย ปิดไว้เป็นค่าเริ่มต้น เมื่อเปิดจะแสดงเวลาท้องถิ่นที่ยืนยัน (HH:mm:ss) ข้างคำบรรยายที่ยืนยันของทั้งสองแหล่ง รวมถึงโหมดเต็มอรรถรส ไม่ใช่เวลาเริ่มพูด เมื่อกลับไปใช้เฉพาะเสียงระบบ ข้อความไมโครโฟนที่ยังอยู่จะมีไอคอนแหล่งเสียงขนาดเล็ก แผงควบคุมลอยยังมีหยุดชั่วคราวและดำเนินต่อ

เลือกคำแปลเท่านั้น ต้นฉบับ + คำแปล หรือต้นฉบับเท่านั้นจากการตั้งค่า แผงลอย หรือถาดระบบ ใช้ ⌘⇧B บน macOS หรือ Ctrl+Shift+B บน Windows/Linux X11 เพื่อเปลี่ยนทันทีโดยไม่หยุดการแปล บน Wayland ตั้งปุ่มลัดระบบให้ `mimi --cycle-subtitle-display` โหมดสองภาษาจับคู่ต้นฉบับกับคำแปลที่ยืนยัน และแสดงต้นฉบับที่รู้จำก่อนระหว่างรอคำแปล

แสดงคำบรรยายเร็วขึ้นจะแสดงข้อความร่างที่ยังเปลี่ยนได้ เมื่อปิดจะรอผลยืนยัน การพูดต่อเนื่องอาจทำให้รอนานขึ้น ตัวเลือกนี้ไม่เปลี่ยนร่างให้เป็นประวัติที่บันทึก

## ข้อผิดพลาดในการรู้จำ

เมื่อรู้จำผิดพลาด คำบรรยายเดิมจะยังอยู่พร้อมเหตุผลของข้อผิดพลาด เปิดแผงควบคุมลอยเพื่อดูรายละเอียดและวิธีแก้ ข้อผิดพลาดการตั้งค่าที่ระบุได้จะมีทางไป เสียงและการแปล ส่วนปัญหาการเชื่อมต่อหรือบริการชั่วคราวจะมีลองอีกครั้ง เมื่อแก้หรือเปลี่ยนการตั้งค่าที่เกี่ยวข้อง เซสชันที่ล้มเหลวจะกลับสู่พร้อมใช้งานโดยไม่เริ่มจับเสียงอัตโนมัติ เปิดคำบรรยายสดอีกครั้งเมื่อพร้อม
