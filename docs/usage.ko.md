# Mimi 사용 안내

서비스 활성화 링크, 인증 정보 입력 항목, 현재 모델은 [서비스 설정 안내(영어)](provider-setup.md)를 참고하세요.

설정 → 일반에서 인터페이스 언어를 선택하세요. 중국어 간체·번체, 영어, 일본어, 독일어, 한국어, 프랑스어, 태국어를 지원합니다. 시스템 설정을 따르는 옵션은 시스템 언어를 사용합니다. 인터페이스 언어를 바꿔도 편집 중인 내용과 자막 상태는 유지됩니다. 인식 언어와 번역 언어는 따로 선택하세요.

## 설치 및 업데이트

1. [최신 릴리스](https://github.com/yuxino/mimi/releases/latest)에서 macOS Apple silicon 또는 Intel DMG, Windows x64 EXE / MSI / 포터블 ZIP, Linux x86_64 .deb / AppImage를 다운로드하세요. 소스에서 빌드할 수도 있습니다.
2. 설정 → 음성 및 번역에서 설정을 추가하고 요청된 서비스 인증 정보를 입력한 뒤 저장하세요. 인식 언어와 번역 언어를 선택하세요.
3. 오디오를 재생하고 자막 페이지에서 실시간 자막을 켜세요. 메뉴 막대나 시스템 트레이의 mimi 아이콘에서도 시작할 수 있습니다. macOS 14.2 이상에서는 모든 앱이나 선택한 앱의 오디오 캡처에 시스템 오디오만 녹음하는 권한을 사용할 수 있습니다. 기존 화면 녹화 권한은 추가 오디오 전용 권한 요청 없이 재사용됩니다. macOS 13–14.1에서는 화면 및 시스템 오디오 녹화 권한이 필요합니다.

서비스 API 인증 정보는 직접 준비해야 하며 사용 요금이 발생할 수 있습니다. 데스크톱 인증 정보는 로컬 파일 권한으로 보호되는 비공개 일반 텍스트 파일에 저장됩니다.

macOS, Windows 설치판, Linux AppImage는 설정 → 일반 → 소프트웨어 업데이트에서 업데이트할 수 있습니다. 다운로드 진행률이 표시되고 완료 후 설치할 수 있습니다. Windows는 설치 후 Mimi를 다시 엽니다. macOS와 Linux AppImage는 다시 시작하여 업데이트를 마치는 별도 동작을 제공합니다. v1.3.8 이전 버전은 한 번 수동 설치한 후 앱 내 업데이트를 사용할 수 있습니다.

사용자 지정 WebSocket 예제, 자동 감지와 언어 힌트의 차이, 각 서비스의 언어 범위는 [음성 서비스 및 언어 설정(영어)](speech-language-setup.md#english)을 참고하세요.

### 플랫폼 지원

- macOS 13 이상(Apple silicon 및 Intel): Apple silicon은 `_aarch64.dmg`, Intel은 `_x64.dmg`를 선택하세요. Intel 패키지는 v1.4.4부터 제공됩니다. 빌드와 서명은 확인했지만 Intel 실기기에서 캡처 및 권한 동작은 아직 검증하지 않았습니다. DMG는 Apple 공증을 받지 않았습니다. 처음 실행할 때 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 선택하세요. 이전 버전에서 업데이트할 때는 아래 권한 안내를 확인하세요.
- Windows x64: 서명되지 않은 미리보기 EXE / MSI와 v1.4.3부터 포터블 ZIP을 제공합니다. SmartScreen 경고가 나타날 수 있습니다. `mimi_<version>_x64-portable.zip`을 압축 해제하고 `mimi.exe`를 실행하세요. WebView2가 설치되어 있어야 합니다(Windows 11에는 보통 포함됩니다). 설정과 비공개 인증 파일은 앱의 사용자 디렉터리, 내보낸 파일은 선택한 위치에 남으며 ZIP 폴더로 옮겨지지 않습니다. 업데이트하려면 Mimi를 종료하고 Releases의 새 ZIP으로 교체하세요. 포터블 버전은 앱 내 설치 프로그램 업데이트를 실행하지 않습니다.
- Linux x86_64 미리보기(Ubuntu 22.04 이상 기준): `.deb`와 AppImage를 제공합니다. PulseAudio 또는 `pipewire-pulse`가 활성화된 PipeWire, 작동하는 기본 출력 장치, 비공개 인증 파일 접근 권한이 필요합니다. 시스템 오디오는 출력 모니터만 사용합니다. 출력 장치를 바꾸면 세션을 다시 시작하세요. X11을 권장합니다. Wayland에서는 위치 지정, 항상 위 표시, 클릭 통과가 데스크톱 환경에 따라 제한될 수 있습니다. Mimi 설정에 표시되는 명령으로 시스템 키보드 단축키를 등록하세요. 트레이 아이콘이 없으면 설정에서 조작할 수 있습니다. 최소화하면 계속 실행되지만 Linux에서 설정 창을 닫으면 Mimi가 종료됩니다. Linux ARM64 패키지는 제공하지 않습니다. [Linux 설치 및 검증(영어)](development/linux.md)을 참고하세요.

### macOS 시스템 오디오 권한

macOS 14.2 이상에서 새로 설치하면 모든 앱과 선택한 앱 모두 시스템 오디오 전용 녹음 권한을 요청합니다. 기존 권한을 바꾸려면 Mimi를 종료하고 시스템 설정 → 개인정보 보호 및 보안에서 Mimi의 화면 및 시스템 오디오 녹화 항목을 제거하거나 끈 뒤 Mimi를 다시 열어 자막을 시작하세요. 요청에 따라 시스템 오디오 전용 녹음을 허용하거나 해당 목록에서 Mimi를 켜세요. macOS가 다시 시작을 요구하면 따르세요. 변경은 선택 사항이며 기존 화면 녹화 권한도 계속 사용할 수 있습니다. 권한이 없으면 오류에서 시스템 권한 페이지를 열어 허용하고 필요한 재시작 후 다시 시도하세요.

### 업데이트 후 macOS가 권한을 다시 요청할 때

현재 macOS 릴리스는 같은 고정 자체 서명 인증서를 사용합니다. v1.4.1 이전에는 빌드마다 바뀌는 임시 서명을 사용했으므로 고정 식별자로 처음 업데이트할 때 녹음 권한을 한 번 더 허용해야 할 수 있습니다. 소스 수정은 이미 설치된 앱을 바꾸지 않습니다. 고정 서명은 빌드마다 식별자가 바뀌는 원인을 없애지만 macOS가 다시는 권한을 요청하지 않는다는 뜻은 아닙니다. 로컬 서명 인증서를 삭제해도 설치된 앱의 식별자는 바뀌지 않으며 이 문제를 해결하지 못합니다. 정식 버전은 `/Applications/mimi.app`, 개발 버전은 `/Applications/mimi-dev.app`을 사용하세요. 서명 설정과 녹음 권한은 각각 유지되며 개발 버전은 정식 버전에서 바뀐 서명 식별자를 이어받지 않습니다.

권한이 켜져 있는데도 캡처가 거부되면 먼저 Mimi를 종료하고 다시 열어 일반 권한 요청을 따르세요. 그래도 실패하면:

1. 문제가 있는 앱을 종료하세요. 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹화(이름은 macOS 버전에 따라 다름)에서 해당 앱의 이전 항목만 제거하세요. 정식 버전은 **mimi**, 개발 버전은 **mimi-dev**입니다.
2. +로 해당 `/Applications/mimi.app` 또는 `/Applications/mimi-dev.app`을 추가하고 권한을 켜세요. 시스템 인증은 직접 완료하세요. 다른 Mimi 버전과 다른 앱의 항목은 남겨 두세요.
3. 같은 앱을 다시 열고 단축키나 시작 버튼으로 자막을 켠 뒤 말소리가 있는 오디오를 재생하세요. 실제로 자막이 나타나는지 확인하세요. 권한 스위치가 켜진 것만으로 복구가 확인되지는 않습니다.

제거하는 것은 이전 녹음 권한이며 인증서나 API 키가 아닙니다. 한 번 시도해도 해결되지 않으면 재설정을 반복하지 마세요. macOS와 Mimi 버전, 설치 출처, 오류를 포함하여 [문제를 보고](https://github.com/yuxino/mimi/issues)하되 API 키나 자막 내용은 넣지 마세요.

이전 시스템 인증 정보는 한 번만 자동으로 가져오며 비공개 일반 텍스트 파일의 저장을 검증한 후 원래 항목을 삭제합니다. 가져올 때 이전 정보 읽기 권한이 필요할 수 있습니다. 이후 전환, 저장, 업데이트는 파일만 사용합니다. 파일이 없거나 손상되어도 키체인으로 돌아가지 않습니다. `codesign`의 서명용 개인 키 접근 요청은 별도의 빌드 시 요청입니다.

## 서비스 설정

데스크톱의 각 서비스 설정은 인식·번역 언어 조합을 기억할 수 있습니다. 설정을 활성화하고 언어를 선택한 뒤 설정 → 음성 및 번역에서 상세 화면을 열어 **현재 언어 기억**을 선택하세요. 조합을 바꾸거나 제거할 때는 **현재 언어로 업데이트** 또는 **저장된 조합 제거**를 직접 선택하세요.

설정을 전환하거나 다시 적용하면 저장된 조합을 복원합니다. 임시 언어 변경은 이를 덮어쓰지 않습니다. 트레이와 플로팅 메뉴에는 설정 이름 아래 저장된 조합이 표시됩니다. 자막 상단의 서비스 정보를 누르면 현재 설정 상세 화면이 열립니다.

## 오디오 및 저장된 세션

시스템 오디오가 기본 입력입니다. 설정이나 플로팅 컨트롤에서 시스템 오디오, 마이크 또는 둘 다 선택할 수 있습니다. 마이크는 시스템 기본 입력 장치를 사용하며 실제 캡처를 시작할 때 필요한 권한을 요청합니다. 두 입력의 인식 연결, 자막, 서비스 사용량은 각각 독립적입니다. 입력을 변경하면 녹음이 꺼집니다. 필요한 경우 저장 및 내보내기에서 다시 켜세요.

macOS와 Windows build 20348 이상에서는 앱 선택기로 특정 앱의 오디오를 고를 수 있습니다. Linux는 시스템 출력 모니터를 캡처하며 이 선택기를 제공하지 않습니다.

설정 → 저장 및 내보내기에서 자막 저장 또는 선택한 오디오 입력 녹음을 선택하세요. 두 옵션 모두 기본값은 꺼짐입니다. 켜면 내용이 세션 중 비공개 로컬 파일에 순차적으로 저장되며 시스템 오디오와 마이크는 따로 저장됩니다. 옵션을 끄면 현재 세션의 해당 내용이 지워집니다. 이미 저장된 세션은 직접 삭제해야 합니다.

다음 데스크톱 세션을 시작해도 화면에 있는 개수 제한 내의 확정 자막은 유지됩니다. 지우기로 제거할 수 있습니다. 이로 인해 저장이 켜지거나 이전 자막이 새 세션 기록에 복사되거나 앱 종료 후 저장하지 않은 자막이 복원되지는 않습니다.

저장 한도는 확정 자막 10,000쌍 / 텍스트 2 MiB, 오디오 64 MiB입니다. 한도에 도달하면 저장을 멈추고 알립니다. 자막 시간은 확정 시점입니다. WAV에는 일시 정지와 재연결 구간이 빠지므로 두 시간축이 직접 일치하지 않습니다.

## 자막 표시

설정에서 다섯 가지 색상(기본은 흰색)을 선택하거나 뒤쪽의 사용자 지정 색상으로 시스템 색상 선택기를 열 수 있습니다. 시스템 오디오와 마이크 색상은 따로 설정합니다. 미리보기와 플로팅 자막은 즉시 바뀌며 몰입 모드에도 적용됩니다. 원문과 번역을 함께 표시할 때 원문은 번역보다 부드러운 명암으로 구분됩니다.

시간 표시는 자막 설정과 플로팅 컨트롤에 있으며 기본값은 꺼짐입니다. 켜면 두 입력의 확정 자막 옆에 현지 확정 시간(HH:mm:ss)이 표시됩니다. 몰입 모드에도 적용되며 발화 시작 시점이 아닙니다. 시스템 오디오만 사용하도록 돌아가도 남아 있는 마이크 자막에는 작은 출처 아이콘이 표시됩니다. 플로팅 컨트롤에서 일시 정지와 재개도 가능합니다.

설정, 플로팅 컨트롤, 트레이에서 번역만, 원문 + 번역, 원문만을 선택하세요. macOS에서는 ⌘⇧B, Windows/Linux X11에서는 Ctrl+Shift+B로 번역 중단 없이 바로 전환할 수 있습니다. Wayland에서는 `mimi --cycle-subtitle-display`에 시스템 단축키를 연결하세요. 원문과 번역 모드에서는 확정된 결과를 쌍으로 표시하며 번역을 기다릴 때 인식한 원문을 먼저 보여 줍니다.

자막 미리 표시를 켜면 나중에 바뀔 수 있는 초안을 보여 줍니다. 끄면 확정 결과를 기다리므로 연속 발화에서 대기 시간이 길어질 수 있습니다. 이 표시 옵션은 초안을 저장된 기록으로 바꾸지 않습니다.

## 인식 오류

인식 오류가 발생해도 기존 자막이 유지되며 이유가 계속 표시됩니다. 플로팅 컨트롤을 열면 자세한 설명과 복구 동작을 볼 수 있습니다. 확인된 설정 오류에는 음성 및 번역 설정, 임시 연결·서비스 오류에는 다시 시도가 제공됩니다. 관련 설정을 수정하거나 전환하면 실패한 세션은 대기 상태로 돌아가며 오디오 캡처를 자동으로 시작하지 않습니다. 준비가 되면 실시간 자막을 다시 켜세요.
