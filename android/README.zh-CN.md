# Mimi 安卓版

把手机播放声音、麦克风或两路声音转成悬浮字幕，支持双语、仅译文或仅原文。

[English](README.md) · [简体中文](README.zh-CN.md) · [项目首页](../README.md)

## 安装与使用

1. **安装应用**：在[下载页](https://github.com/yuxino/mimi/releases/latest)选择 `.apk` 文件，下载后在 Android 10 或更新系统上安装。
2. **配置服务**：打开「服务」，添加一个语音服务，填写密钥等信息后保存。首次添加的配置会自动选中；服务选择和密钥获取方法见[配置指南](../docs/provider-setup.zh-CN.md#choose)。
3. **开启字幕**：在「字幕」中选择音源、识别语言和翻译语言，点击开始。按提示允许悬浮窗和录音权限；包含系统声音时才需要系统捕获授权。
4. **播放内容**：切换到视频、直播等应用，播放含有人声的内容。字幕会悬浮显示；开启沉浸模式后，触摸操作可穿过字幕。

Mimi 本身免费，云服务可能收费。云端识别会接收采集的音频，远程文字翻译会接收识别文字。安卓服务配置需单独填写，不会从电脑版自动同步。

## 使用提示

- **音源**：默认采集其他应用的播放声音，可主动选择麦克风或双输入。双输入各自采集和识别，字幕标明来源，不混音；切换前须停止。仅选麦克风不会弹出屏幕采集授权；仅选系统声音不会打开麦克风。Android 的录音权限也是播放声音采集所必需的。
- **没有字幕**：先确认已开启字幕、选中有效的服务配置，且内容中有人声。部分应用禁止音频采集，受保护内容可能无法识别。采集系统声音时，每次开始需再次同意系统捕获提示。
- **字幕显示**：可调整字号、颜色、位置和显示模式。打开 Mimi 自身页面时，悬浮字幕会暂时隐藏，识别仍会继续；离开后恢复。
- **保留字幕**：新安装默认保留最近 3 句已确认字幕，已有用户保持原设置。可调整保留数量；停止后仍可阅读有限的已确认字幕，开始新会话时清空。字幕页的“保存字幕”默认关闭，开始前主动开启后会把原文、译文及音源写入应用私有文件。“已保存会话”支持分页查看、TXT/Markdown 导出和确认删除。关闭保存会删除当前会话的已存内容，过去的会话需手动删除；安卓仍不支持录音文件导出。
- **服务范围**：支持阿里云、OpenAI、Gemini、Azure、火山引擎、腾讯云、百度和 xAI。阿里云、OpenAI、Gemini 和 Azure 可选「ASR + MT」，xAI 可选流式识别，再单独配置文字翻译；步骤见[文字翻译指南](../docs/provider-setup.zh-CN.md#text-translation)。安卓不支持 Apple 本地服务或自定义语音识别。

遇到问题可[提交反馈](https://github.com/yuxino/mimi/issues)，请附上手机系统版本、使用的服务和具体操作，不要公开密钥或私密字幕。开发与构建说明见[英文技术文档](README.md)。
